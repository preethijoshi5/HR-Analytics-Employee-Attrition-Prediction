# HR Analytics: Employee Attrition Prediction using Machine Learning

## 📌 Project Overview

Employee attrition is a major challenge for organizations as it impacts productivity, increases recruitment costs, and affects overall business performance. This project analyzes employee data and builds machine learning models to predict whether an employee is likely to leave the company.

---

## 🎯 Objective

- Analyze employee attrition patterns.
- Identify the key factors influencing attrition.
- Build and evaluate machine learning models.
- Provide business recommendations to improve employee retention.

---

## 📂 Dataset

- IBM HR Analytics Employee Attrition Dataset
- Total Records: **1470**
- Features: **31**
- Target Variable: **Attrition**

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## 📊 Exploratory Data Analysis

The following analyses were performed:

- Employee Attrition Distribution
- Department-wise Attrition
- Overtime Analysis
- Job Satisfaction Analysis
- Work-Life Balance Analysis
- Monthly Income Analysis
- Age Analysis
- Correlation Heatmap

---

## 🤖 Machine Learning Models

The following classification models were trained and evaluated:

- Logistic Regression
- Decision Tree
- Random Forest

---

## 📈 Model Performance

| Model               | Accuracy  |
|---------------------|------------|
| Logistic Regression | **87.41%** |
| Decision Tree       | **79.93%** |
| Random Forest       | **88.10%** |

**Final Selected Model:** Logistic Regression

---

## 🔍 Key Insights

- Employees working overtime were more likely to leave.
- Lower monthly income was associated with higher attrition.
- Younger employees showed higher attrition rates.
- Job satisfaction and work-life balance significantly influenced employee retention.

---

## 💡 Business Recommendations

- Reduce excessive overtime.
- Improve employee satisfaction.
- Enhance work-life balance initiatives.
- Review compensation strategies.
- Implement targeted employee retention programs.
